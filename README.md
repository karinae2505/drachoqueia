# Dra. Choque AI

## Descripción

Dra. Choque AI es un asistente inteligente desarrollado en Python que responde consultas sobre accidentes de tránsito utilizando un documento PDF como base de conocimiento.

## Tecnologías utilizadas

- Python
- LangChain
- PyPDF
- GitHub

## Funcionalidades

- Lectura de un documento PDF.
- Respuestas en lenguaje natural.
- Consultas sobre accidentes de tránsito.

## Ejemplos de consultas

- ¿Qué debo hacer después de un accidente?
- ¿Tengo que llamar a la policía?
- ¿Qué documentación debo conservar?
- ¿Qué hago si el otro conductor se dio a la fuga?
